## 画像（リモート URL）

段落中に単独で置かれた `![alt](src)` は独立した画像ブロックになる。src が
http(s) URL の場合は render.ts の仕組み（docDefinition.images 経由）でダウンロード
して埋め込む。width/height を明示しない場合は本文幅に収まるよう自動で縮小される。

## 画像（ローカルファイルパス）

src がローカルファイルパスの場合、ダウンロードは不要で pdfkit が直接読み込む。

![代替テキスト](sample.jpeg)

## 画像（幅・高さを明示指定）

`<img width height>` で明示した値は、本文幅に収める自動調整より優先される。

<img src="sample.jpeg" width="200" height="100">

## 画像（他のテキストと混在する場合）

pdfmake の text 配列そのものは画像を行内要素として描画できない
（型定義上は受け付けるが実装が対応していない）。そのため
rehypeDdast.ts は画像を黙って消さず、前後のテキストを別々の段落に分割して
画像を独立したブロックとして挟み込む。

文中に![img](sample.jpeg)入れるとこうなる。

<!-- pdf-page-break -->

画像の直後に明示的な改ページマーカーを置いた段落。このマーカー自体はどの見出しの
直前にも置いていない（見出しの自動改ページと衝突しないよう、カード状の UI 要素を
段落として並べる利用を想定し、カード＝段落の切れ目に置く用途を想定）。

## テーブル（幅指定なし）

指定の無い列は `theme.table.defaultColumnWidth`（既定 "auto"）のままになる。
幅を指定していないのに列を広げるような調整はしない。

| 項目 | 値 |
|---|---|
| A | 1 |
| B | 2 |

## テーブル（`<!-- width="..." -->` で幅指定あり）

1列目に `<!-- width="*" -->`、2列目に `<!-- width="80" -->`（80pt 固定）を指定。

| 名前<!-- width="*" --> | ステータス<!-- width="80" --> |
|---|---|
| 長い名前のサンプルテキストが入っても幅が保たれることを確認する行 | OK |
| 短い名前 | NG |
