# Security Policy

## Supported Versions

remark-pdfmake is pre-1.0 (`0.x`). Security fixes are made against the latest released
version on the `main` branch; older `0.x` releases are not backported.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a suspected security vulnerability.

Instead, use GitHub's private reporting:

1. Go to the [Security tab](https://github.com/iret-m-nakamura/remark-pdfmake/security)
   of this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce (a minimal Markdown input and/or code snippet is ideal).
- The affected version(s).

You should receive an acknowledgement within a few days. Once a fix is available, a
security advisory and a patched release will be published, and credit will be given to
the reporter unless anonymity is requested.
